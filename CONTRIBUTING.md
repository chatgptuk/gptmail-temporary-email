# Contributing to GPTMail public documentation

Thank you for helping improve GPTMail's public guides.

## Useful contributions

This repository welcomes:

- corrections to inaccurate or outdated documentation;
- clearer troubleshooting steps;
- accessibility and readability improvements;
- careful translations that preserve the meaning of the English source;
- links to reliable sources when a technical claim needs verification.

This repository is not the place for inbox support, abuse reports, account questions, or security disclosures.

## Protect private information

Never include any of the following in a public issue, pull request, commit, screenshot, or example:

- an active or recently used inbox address;
- email bodies, attachments, verification codes, or private links;
- passwords, API keys, authorization headers, cookies, or tokens;
- personal information or third-party confidential data.

Send private support and security reports to **support@chatgpt.org.uk**.

## Writing guidelines

- Write for a person trying to complete a real task.
- Prefer specific steps over promotional language.
- Keep claims factual and verifiable.
- Do not repeat keywords unnaturally or add pages only for search engines.
- Explain limitations and safety boundaries where they affect the reader's decision.
- Use examples that cannot expose a real inbox or third-party data.

For small corrections, use the documentation feedback issue form. For a substantial change, open a focused pull request that explains what changed and why.
