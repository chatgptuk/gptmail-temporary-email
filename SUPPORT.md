# GPTMail Support

This repository contains public product guides. It is not connected to an individual inbox and should not be used to publish private account information.

## Before asking for help

1. Read the [GPTMail help center](https://mail.chatgpt.org.uk/help).
2. Follow the [verification email troubleshooting checklist](docs/verification-email-not-received.md).
3. For API behavior, check the live [developer documentation](https://mail.chatgpt.org.uk/api).
4. Confirm that the domain is currently active and that the address was copied exactly.

## Contact

For product support, abuse reports, data requests, compliance matters, or a problem that requires private details, email **support@chatgpt.org.uk**.

For documentation corrections that contain no private data, use this repository's documentation feedback form.

## Never publish these in a GitHub issue

- a complete temporary email address that is still active;
- email body text, headers, attachments, screenshots, or verification codes;
- confirmation links, magic links, password-reset links, or session URLs;
- private-domain passwords;
- API keys, refresh tokens, mailbox tokens, or authorization headers;
- personal names, phone numbers, addresses, identity documents, or payment details;
- private DNS or account screenshots.

Redact examples before sharing them. Replace real addresses with values such as `example@example.com` and secrets with `[redacted]`.

## Domain availability

Public domains may become unavailable because their registration expires or their MX records change. Some public domains are controlled by third parties, and even a GPTMail-controlled domain may not be renewed after expiry. Support cannot guarantee continued availability or restore a domain that is no longer controlled. Generate an address on another active domain instead.

Third-party websites can also block disposable-email domains. GPTMail cannot override another website's acceptance policy.
